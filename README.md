# Connect 4 — Human vs AI

A browser-based Connect 4 game built for **GAME-GD2**.

The project demonstrates a real game-playing AI using:

- Minimax search
- Alpha-beta pruning
- Heuristic board evaluation
- Center-first move ordering
- Depth-limited search

## Project Status

Architecture and implementation plan are established. The repository is currently entering Stage 1: project foundation.

See [PROJECT_CONTEXT.md](./PROJECT_CONTEXT.md) for the complete source-of-truth architecture, implementation stages, testing matrix, AI design, and definition of done.

## Planned Stack

- Vite
- React
- TypeScript
- CSS

No backend or external AI service is required.

## GAME-GD2 Requirements

The finished game will provide:

- Legal move detection
- Turn switching
- Win/draw detection
- Human vs computer gameplay
- Minimax/negamax search
- Alpha-beta pruning
- Heuristic evaluation
- Clear valid-move and game-state UI
- New Game flow
- Responsive and accessible presentation
